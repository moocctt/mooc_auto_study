# 词汇表（GLOSSARY）

领域名词按实际使用沉淀于此；架构深挖（improve-codebase-architecture）落地的模块名同步登记。

## 页面与壳
- **概览**（`#/report`）——首屏：学时账单、KPI、截止提醒、推荐、统计、热力图、运行日志
- **课程**（`#/tasks`）——我的任务 + 课程库两个标签
- **设置**（`#/settings`）——账号 / 偏好 / 关于与隐私（运行标签已并入日志浮层）

## 领域概念
- **学时账单**——年度必修学时进度（网络自学 + 集中培训两段口径）
- **学时账本**——每日学时增量的本机账（base/last 口径，src/lib/today.ts）；`todayHoursTotal` 是今日学时唯一口径
- **扫码通道**——APP 扫码（deriveQRCode/loginCheck）与微信扫码（createQRCode/checkUUIDStatus/weChat-auth）两条通道；协议在 src/lib/qr.ts
- **凭据保管箱**（vault）——chrome.storage.local 里的密码与令牌备份（按平台下发的有效期自动续期）；src/lib/vault.ts
- **本地闸门**——登录节流与失败锁定（15s / 3 次 / 30 分钟），src/lib/loginGuard.ts；所有提交账号密码的入口共用（addAccount 内部）
- **浮层互斥**——小节抽屉与运行日志浮层同层，开一个关另一个（Overlay.tsx + store）

## 架构模块（深挖产物）
- **consoleApi**——UI/Actions 的具名操作接口（src/lib/api.ts 返回对象上），替代字符串路径垫片；fetch 面保留给测试/桩/demo
- **PlatformClient**——平台 HTTP 协议适配器（src/lib/platform.ts）：登录、任务、进度、课程库查询
- **ActivityBody**——运行记录 + 实时日志的内容组件（设置页内嵌与日志浮层共用）

## 界面术语（文案审计 2026-11-14 定名，全产品统一，不得混用）
- **快速刷课**——后台按小节连播单门课程推进进度（runCourse）；按钮文案「快速刷课」，勿写「自动学习/刷完」
- **无人值守看课**——在官网真实页面上自动播放并按队列连续推进（autopilot）；按钮/卡片用全称「无人值守看课」，状态可简称「值守」（如「值守已停止」），勿写「挂机/代学」
- **账号密码登录**——三通道之一的正式名称（与「APP 扫码」「微信扫码」并列）；用户可见文案用全称，勿写「账密」（代码注释不受限）
- **学时账单**——网络自学/集中培训分开核算的年度账单视图；勿写「学时统计」（「学习统计」另指按日累计的统计卡）
- **状态显示名「已开始」**——任务/小节状态的数据值保持平台原值「学习中」，用户可见文案一律显示「已开始」（纯生命周期词：未开始/已开始/已完成/已过期），避免被误读为「自动化正在学习」；过滤标签同理（筛选值不变）
- **运行记录「操作」列前缀**——按完成机制区分：`快刷 <名称>`（后台提交学习轮次）/ `值守 <名称>`（无人值守真实播放）；一键完成待学任务记为 `快刷待学任务`
