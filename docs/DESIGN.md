# 设计说明 — 烟草网络学院学习助手

> 由 `impeccable document` 从既有实现与主站实测值整理（2026-11-07）。改动视觉时先读这里，保持同一套判断。

> **ext-native 分支注**：本文档写于 WXT+React+Tailwind 时代。「样式写法」一节的 Tailwind 工具类约定已被原生 CSS（`extension/console/style.css`，语义类名 + `--brand` 系等 CSS 变量 token；2026-11-14 核验全部色值无漂移）取代；文中 `src/...` 路径对应现 `extension/...`。视觉判断（品牌绿、直角、白卡浅底、PingFang 栈、间距/圆角实测值）仍然有效。

## 产品与表面

- **产品**：Chrome/Edge 扩展，管理本人烟草网络学院（mooc.ctt.cn）账号的学习进度、任务与截止提醒。
- **表面模式**：Operate。用户来完成任务：看清学时差多少、哪门课要到期、去哪门课接着学。表达力让位于扫描效率与一致性。
- **视觉权威**：主站 UI 是基准（用户明确要求"像素级克隆"）。品牌绿、直角、白卡浅底、PingFang 字体栈来自主站实测，不是自创。

- **深色模式：暂缓（用户拍板 2026-11-07）**。浅色是与主站对齐的刻意身份，非缺失。全部色彩已 token 化（`@theme`），
  若未来需要：实现路径 = `@media (prefers-color-scheme: dark)` 覆盖 `extension/console/style.css` 的 `--brand` 系等变量 + 登录页保持浅色（官网克隆身份）
  + 全页 4.5:1 对比度回归。勿在未拍板前局部实现。

## 版式

- 桌面：外壳 `h-[100dvh] overflow-hidden`，侧栏 224px 满高、**内容区自己竖向滚动**（文档不滚动，
  侧栏与顶栏恒定）；账号区常驻侧栏底部。
- 运行日志入口固定在顶栏图标（`!STORE` 才显示），任何页面都能唤起同一浮层。 `max-w-5xl`，页面内边距 24px，卡片间距 16px，卡片内边距 20px。
- 登录页按主站坐标：70px 页头 / 740px 天空横幅（窄屏 480） / 800×414 白卡（右留 90px）/ 输入与按钮 312×40 / 标题 19px-600。
  品牌标用真实应用图标（`/icon/48.png`，与工具栏同一份），不用「学」字当 logo。
  布局按主站做法：**左栏常驻 APP 二维码**（过期自动换新码，直到登录成功或离开页面），
  **右栏在「账号登录表单 / 微信二维码」之间切换**，入口是**卡片右上角的绿色折角**：
  折角里画的是**半个二维码**（白色定位角被折线切掉一角, SVG），让人一眼联想到扫码；
  外层是 44×44 的真实 `<button>`（`aria-label` 写目的地），hover / focus 时在左侧浮出文字
  （「微信扫码」/「返回账号密码」），键盘可达、可读屏。折角图形不随模式变化, 动作由文字说明。
  二维码常驻轮询（过期自动换新）并提供「刷新二维码」手动入口。
  折角里的图形随模式变：账密表单 → 半个二维码（扫码）；微信模式 → 半个电脑屏（回账密），
  切换时用户能看到图标在变。
  右下折角是「下载 APP」按钮（半部手机 + 下箭头）：弹出弹窗给两个本地生成的二维码
  （Android APK 直链 / 鸿蒙·华为应用市场）＋官方下载引导页链接（现 `extension/lib/appdownload.js` + console/overlays.js）。
  页面上不再有「找回密码」与「扫码下载APP」。
- 窄屏（≤860 / ≤620）：卡片单列、隐藏扫码栏与下载徽标、页头 60px、横幅 240px。扩展弹层常用宽度 420px，必须在这里可用。

## 样式写法（强制）

- 【ext-native 已改】布局与外观用原生 CSS（`extension/console/style.css`，语义类名；颜色/动效沿用 `--color-*` 等旧 token 值）。组件里不写内联 `style`（动态数值除外，如进度条宽度、热力图网格坐标）。

## 页面

导航三项：**概览 / 课程 / 设置**。首屏叫「概览」而不是「学习」——它回答的是「现在什么状态、
差多少、先做哪门」，不是在描述学习这个动作；功能标题（学习统计、学习热力图）沿用原名。

## 组件约定

- **标签页**：`flex gap-1 border-b border-line` 容器 + 按钮类
  `-mb-px border-b-2 border-transparent … aria-selected:border-brand aria-selected:text-brand`，
  用 `aria-selected` 变体表达激活态，不用实心按钮块包在边框里。
- **按钮**：主操作 `bg-brand-mid` 白字；次操作 1px `line` 边框，hover 变主绿；禁用 `opacity-50`。
- **状态**：`Pill`（学习中/已完成/已过期/必修），语义色固定，不做装饰性变色。
- **列表行**：任务行只作鼠标快捷区（整行可点开小节），**不再**给行加 `role="button"`/键盘处理 ——
  行内已有链接与按钮，再套一层行级按钮会造成嵌套可交互；键盘用户走右侧「小节」按钮。
  完成态只降标题色，不整行降透明度（会掉下 4.5:1）。

## 无障碍与浏览器原生面

- 焦点环：`:focus-visible` 2px `#007556` + 1px offset；鼠标点击不出环。
- 选区 `#CDEAE1`、caret 主绿、滚动条 `#D5D5D5`、占位符 `#757575`（4.6:1）。
- 弹窗与抽屉：`role="dialog"` + `aria-modal` + Esc 关闭 + 关闭按钮有 `aria-label`。
- 正文与占位符 ≥4.5:1；小字 11–12px 只用于标签，不用于阅读正文。

## 版面习惯

- 热力图铺满卡片宽度: 周数按可用宽度在 26~53 之间自适应（`(vw-340)/15` 取整并夹紧）,
  保证每格 12~16px 且不留空白；不要用「右侧塞统计栏」的办法填留白。
- 窄屏优先保内容: 任务行在 <640px 折成两行（标题整行 + 操作右对齐）, 而不是把课名截断。

## 动效

- 基线（`style.css`）：`--motion-fast 120ms` / `--motion-base 200ms` / `--motion-slow 320ms`，
  缓动 `cubic-bezier(.2,0,0,1)`；只动 `transform` / `opacity`，不动布局属性。
- **读数动画**（`AnimatedNum`）：数字从 0 涨到目标值，之后数值变化从上次值续涨（320ms，ease-out cubic）；
  负值按 0 兜底（学时数据加载中可能出现瞬时负值）。用于概览账单、KPI 卡、学习统计四格、热力图合计。
- 进度条首屏从 0 推进；抽屉从右侧滑入 16px + 遮罩淡入；Toast/弹窗淡入上移 4px；
  切页时内容上移淡入；侧栏待学角标数值变化弹一下；热力图格子按列 5ms 递增淡入（≤260ms）。
- 列表/封面切换、筛选变化、搜索结果刷新都走 200ms 交叉淡入；搜索结果逐项 15ms 递增（封顶 200ms）；
  按钮按下 `active:scale-[0.98]`（链接不加，避免整页都在动）。
- `prefers-reduced-motion: reduce` 时全部退化为终态（CSS 里统一 0.01ms，读数直接跳终值）。

## 课程库

- **类型**：热门（平台默认排序的全类型混合, 不传 type）/ 课程 / 专题 / 考试 / 调研 / 直播。
  类型 id 在 `src/lib/library.ts`；考试/调研/直播的 id 是推测值 —— 请求后会用返回项自带的 type
  回验，不匹配就当「该类型暂无内容」，绝不能张冠李戴。
- **分页**：两个标签页统一每页 **12 项**（`src/lib/core.ts` 的 `PAGE_SIZE`，与 2/3/4 列封面网格整除），
  共用 `Pagination` 组件与「项」单位；组件显式写出「每页 N / 末页 M」，避免把页数误读成 `页数×12`。
- **课程库块加载**：平台 `findPageForGlobalSearch` 接受大 `pageSize` 且返回 `recordCount` 总数（实测 8555）。
  浏览（空关键词）一次取 `LIB_BLOCK_PAGES=20` 页（240 条），前端切成 12 条/页；`recordCount` 算总页数，
  跳页按目标页换算块号直接取对应块。有关键词搜索走平台多关键词合并，仍按单页取。
  页结果按 **`(账号, 关键词, 类型, 页码)`** 缓存并防抖落盘到 `mooc.libCache.v1`（TTL 6h / 最多 120 页），
  内存、落盘、在途请求三者都按账号隔离，切账号不会串用上一个账号可见的课程库结果。
  启动时读回内存，跨会话不重复查询；换关键词或类型不清缓存（key 天然隔离），只丢弃在途结果。
  翻页只换数据：保留旧卡片、分页条独立于结果区常驻，不把搜索区整体卸载重挂。
- **缓存分层与失效**：`invalidate(scope)` 是唯一失效入口（`library / profile / tasks / all`）。
  账号变化由 `loadState` 统一检测（覆盖登录 / 切账号 / 添加账号 / 导入备份），切账号另显式调用；
  登录 / 切账号 / 登出 / 手动刷新 → `all`，学习结束 / 跨日 / 页面重新可见 → `tasks`。
  「刷新数据」走 `forceRefreshAll()`，能绕过课程库 6h 缓存并原地重取当前页。
  姓名头像 **6h 真 TTL**（`mooc.console.profileSyncAt.v1`，跨会话、失败回滚）、日历 ICS 15min；
  学时 / 进度 / 章节 / 运行日志始终不缓存，由 `refreshAll` 每次直连平台，避免脏读。
- **封面卡片**：两个标签页共用 `src/components/ui.tsx` 的 `CARD_GRID / CARD_ITEM / CARD_ARTICLE / CARD_COVER / CARD_BODY`
  规格（圆角、16:9 封面、内边距、同行等高）。改视觉只改这一份常量，避免两个标签页再次跑偏。
- **账户资料**：`fetchProfile` 从 `/api/v1/human/member/center`（缺头像时兜底 `/api/v1/system/setting`）
  取姓名与头像，写进 `Account.displayName / avatar`；左下角优先显示平台头像，失败回退首字母。
  实测（2026-11-08 真实账号）：`headPortraitPath` **不在响应顶层**，嵌在 `memberDetail` /
  `currentUser` 里，值形如 `default/M00/04/42/xxx.jpg`；正确前缀是 `https://mooc.ctt.cn/`
  （300×300 可加载），**不要**用 `cdnPreviewAddress`（实测 404）。`headPortrait` 是文件 UUID，仅作末位兜底。
  `POST /api/profile/sync` 在 `loadState` 时按 6h 真 TTL 重拉（节流不算 TTL），官网换账号后左下角会跟着更新。
- **无人值守看课**：队列由 `autopilotQueueOf` 生成（待学课程/专题，必修排最前），每项 URL 经
  `ssoCourseUrl` 带入当前账号登录态。入口有两个：首页快捷操作（全量待学，必修优先）、
  **每个任务自带的「自动学习」按钮**（`startAutopilotFrom`，把这一门排到队首，其后接着播其余待学任务）。
  按钮在封面卡片（`data-testid="card-autopilot"`）与列表行（`row-autopilot`）上都出现，
  仅当 `isAutopilotTarget(r)` 为真（课程/专题 + 可播放 + 未开始/学习中）；它和首页快捷操作一样
  不受 `!STORE && unlocked` 的隐藏开关限制，工具栏上的页面级「一键无人值守播放」已移除。
- **两个动作的措辞与图标**：`快速刷课`（后台按小节连播，图标脉冲 `pulse`）与
  `自动学习`（无人值守队列，图标播放 `play`）——两者图标刻意与直觉相反，保持全站（卡片/列表）一致。
  「我的任务」与「课程库」的封面卡片和列表行都放这两个按钮：课程库课程可能还没加入我的任务，
  用 `startAutopilotFromLibrary`（`data-testid="lib-card-autopilot"` / `lib-row-autopilot`）把它排到队首，
  平台打开详情页时会自动报名；队列其余部分仍是待学任务（必修优先）。
- **自动学习 = 真实播放到 100%**（内容脚本 `src/entrypoints/mooc.content.ts`，2s 一拍）：
  - 平台要求「点击播放按钮」：先点播放器自己的 `.vjs-play-control`，再退到大播放钮，最后才 `video.play()`（静音兜底）。
  - 画质统一切「普清」；切档实测是**无缝换源不重播**（视频时间连续）。控件结构：外层 `.vjs-subs-caps-button`
    含菜单 `li.vjs-menu-item`（其它档位）与内层 `button > .vjs-control-text`（**当前**画质），所以当前画质
    只能读 `.vjs-control-text`，不能用控件全文匹配。开启值守时**无论播到哪都先切一次普清**
    （后台记 `mooc.autopilotOnAt` 激活时间戳，内容脚本比对去重，页面重载不重复切）；其余只在每节开头 30s 内切。
  - 以 `video.ended` / `currentTime ≈ duration` 判定真实 100%，**不拖动进度条、不跳播**；播完再等平台记账
    （`video-progress` 上报 → `course-section-progress` 的 `finishStatus=2`、`completedRate=100`），
    核对通过才切下一节 / 下一门。目录文案「复习」也视为完成（平台把完成态显示成「复习」）。
  - 网站禁止多开：后台 `openCourseTab` 复用**同一个专用标签页**（`mooc.autopilotTab`），串行化开课，
    URL 加一次性 `?ap=<ts>` 让「只有 hash 不同」的 SSO 链接也能整页导航；落不到目标课程路由就重发一次。
    同时开两个课程详情页会被平台顶到 `#/study/errors/<id>`，脚本会点「继续学习」兜回。
  - **值守标签页固定(pin) + 静音(muted)**：开课/换课时 `tabs.update({pinned:true})` + `tabs.update({muted:true})`，
    用户可继续在其它标签页工作；鼠标完全不被占用（脚本内是合成事件，不动真实光标）。
    后台标签页 2s 轮询会被 Chrome 降频，内容脚本用 `play`/`ended` 媒体事件（捕获监听，不受节流）兜底。
    实测：静音+后台播放到 100%，平台正常记账（`finishStatus=2 / completedRate=100 / studyTotalTime≈视频时长`）。
  - **控制台标签页只保留一个**：`openConsoleTab` 先查已有 `console.html` 标签页，命中就复用并聚焦窗口
    （工具栏图标点击、首次安装引导都走它），不再各开一个。
  - **课程页点扩展图标直达自动学习**：活跃标签页是平台课程/专题详情页（`#/study/course/detail/<1|2>&<id>`，
    判断在 `src/lib/links.ts#isCourseDetailUrl`，有单测）时，点工具栏图标直接在**当前页**开/关自动学习 ——
    用户已登录、已在播放器页，无需再走 SSO；开启时把本标签页登记为值守专用标签页（`mooc.autopilotTab`）
    并 pin+mute，之后队列换课复用同一标签页。再次点击 = 停止。非课程页点击仍是打开/聚焦控制台。
    值守关闭时图标悬停提示跟随活跃标签页（课程页显示「点击开始自动学习本课程/专题」），运行中提示由心跳维护。
  - **工具栏图标有值守角标**：内容脚本每次 `setStatus` 顺带发 `AUTOPILOT_TICK` 心跳，后台据此给扩展图标
    挂角标 —— 播放中绿 ▶（#16a34a）、值守在跑但没在播（切节/等记账/处理弹窗）橙 …（#f59e0b）、
    停止即清掉；tooltip 同步「自动学习中 · <状态文案>」。开关变化走 `storage.onChanged`，
    SW 冷启动/浏览器重启后按持久化开关恢复角标。验证脚本 `tests/badge-check.mjs`。
- **动作按钮**：课程/任务的卡片和行不再放「去学习/平台」按钮 —— 标题/封面本身就是平台链接，
  行点击开小节抽屉（抽屉里每节保留平台直达）。

## 浮层

- 右侧浮层外壳只有一份：`src/components/Overlay.tsx`（遮罩 + 滑入 + Esc + 焦点进入/归还），
  小节抽屉与运行日志共用它，不要再写第二套。
- **运行日志**是全局浮层（`LogOverlay`，`openLog(runId?)` 唤起）：顶栏日志按钮、概览「最近运行」
  记录（点击 chip/表格行即过滤到该次运行）都打开它；运行控制台页内版共用 `ActivityBody`。

## 声音

- 只有**结果音**: 完成（上行五度 660→990Hz）与失败（下行 300→240Hz），用 Web Audio 正弦/三角波合成，不落地音频文件。
- 不为点击、滚动、悬停发声；不循环、不抢占。默认开启，可在「设置 → 偏好 → 提示音」关闭（`localStorage` 记住）。
