# 产品功能定义 — 烟草网络学院 · 学习助手（web 版）

> v0.2 · 2026-11-13。本文回答「这个产品是什么、有什么、边界在哪」；实现细节见
> [ALIGNMENT.md](./ALIGNMENT.md)（与 extension 分支逐项对齐）与 [API-NOTES.md](./API-NOTES.md)（平台接口考古）。

## 一句话定位

多用户 Web 应用：注册站点账号、绑定烟草网络学院（mooc.ctt.cn）账号，把必修网络学时的完成过程托管给后台引擎——总览看进度、任务页启动、课程库找课，全程不打开平台页面。

## 用户与场景

烟草系统在职职工，用自己的学院账号完成年度必修学时。工作时段在办公电脑打开，核心诉求按优先级：

1. **看清还差多少**——网络自学 / 集中培训两条线分别差多少，必修有没有快到期的；
2. **把网课学时挂上去**——选一门课让引擎代跑，自己干别的；
3. **找课**——按名字在 12 类内容里检索，判断学分/学时再决定学哪门。

设计基调（`.impeccable.md`）：沉稳、可信、清爽。学时是「账单」，不是游戏分数。

## 核心概念

| 概念 | 定义 |
| :-- | :-- |
| 站点账号 | 本应用自己的账号（用户名+密码），多用户互不可见；会话用 httpOnly cookie + 服务端 sessions 表 |
| 平台账号 | 烟草网络学院的账号；绑定后密码 AES-256-GCM 加密落库（密钥来自环境变量，固定不变，否则旧密文解不开），access_token 只驻留服务端内存，进程退出即失效 |
| 引擎 | 服务端的后台任务循环：登录平台 → 拉任务 → 逐课程逐小节上报学时；同一用户同一时刻最多一个实例 |

## 功能定义

### 1. 账号体系（站点侧）

- 注册 / 登录 / 退出：`POST /api/auth/register|login|logout`，`GET /api/auth/me`。
- 密码以 scrypt 哈希存储；登录假哈希防计时探测；会话 TTL 30 天（可配），过期会话每日清扫。
- 限流：认证接口 30 次/15 分钟/IP（伪造 X-Forwarded-For 不生效，Nginx 追加真实 IP，信任右起第二跳）；`/me` 300 次/分钟。

### 2. 平台账号绑定

- `GET/POST/DELETE /api/platform`：状态 / 绑定（用户名+密码+单位名，密码加密入库）/ 解绑。
- 登录失败一次即向用户报错，不自动重试（防锁定：平台 90907-90910 连错 3 次锁 24h）。
- 运行中禁止换绑 / 解绑；绑定状态在总览页展示并可一键解绑。
- 令牌失效（401 / 90901 / 90902）时引擎用库中密文自动重登一次，学时账不会记错人（会话归属校验）。

### 3. 总览（Dashboard）

- **双轨学时账单**：网络自学（必修课）与集中培训（班级/面授）分开核算，各配进度条 + 完成百分比；集中培训缺口单独提示「面授学时网课补不上」——这是产品最重要的诚实性设计，网课进度高不代表年度达标。数据源 `detail-hour-member`，数字与平台个人中心一致。
- **26 周学习热力图**：GitHub 贡献图风格的日学时聚合（网络自学 + 专题两源，学时归到最后访问日，与 extension 同款近似），hover 看每日学时，今日/本周/本月/本年汇总。产品的记忆点。
- **必修临近截止清单**：7 天内要截止的必修任务，按截止时间升序，剩余时间分级表达（<1h 分钟 / <24h 小时 / 其余天，一位小数），颜色之外永远有文字。

### 4. 任务页与引擎

- **任务列表**：平台「我的任务」全量拉取（10 页 × 500），支持按名字搜索、只看必修，实时计数。
- **引擎控制**：启动全部 / 启动单课（可从任务行或课程库指定）/ 停止；状态胶囊实时显示「运行中 · 课程 · 小节 · 轮次 · 已提交数」；实时日志（环形 500 行，自动滚底，`role=log`）。
- **上报规则**（与油猴脚本同一套引擎，被平台验证过的参数）：
  - 单次上报 ≤90s（实测 ≥120s 被平台静默丢弃），真实流逝时间随机回填；
  - 视频/音频走 video-progress，文档走 doc-progress；scorm/考试/问卷/评估/任务/课件自动跳过；
  - 嵌套课程（关联课）递归处理，深度 ≤2；
  - **自动熔断**：平台剩余学时连续 2 轮不下降 → 判定配额满，自动停止；单课连续 5 小节无进展 → 跳出该课；
  - 令牌失效自动重登一次再续跑。
- **运行保护**：运行中不可换绑/解绑/退出登录；异常（含引擎崩溃）先把登录框恢复再报错。

### 5. 课程库

- 12 类内容检索：课程、专题、班级、考试、调研、直播、话题、知识、微吼直播、新闻资讯、交流园地、专区专家——逐类接入平台真实接口（微吼/专家端点有效但平台暂无数据）。
- 课程/专题支持**封面视图**（封面卡 + 兜底链），其余类型列表视图；结果带学分/学时/起止时间。
- **已加入任务标记**：命中项若已在「我的任务」里则标绿，避免重复启动。
- 点「学」直接把该课程 id 交给引擎启动。

### 6. 学习记录明细（热力图下钻）

点热力图任意一天，弹出当日学习流水：每门课的名称、学时（分钟）、必修/选修、课程/专题，按学时降序，合计分钟数。数据与热力图同源（person-courselog + subject-log），只在点开时拉取。

### 7. 日程页与日历导出

- 班级/考试/调研/直播四类平台活动全量拉取（无关键词即可分页拉全），窗口为过去 7 天 ～ 未来一年，按开始时间升序；状态分「未开始/进行中/已结束」，可按类型筛选。
- **ICS 日历导出**：日程活动生成整段事件（有起止时间）＋ 7 天内要截止的必修任务生成全天截止事件（各带 3 天提前提醒），可导入 Outlook / 手机日历。数据源与参数见 docs/API-NOTES.md。

### 8. 定时引擎

每天指定时刻自动「开始全部」（按必修优先排序推进），配额满自动停止；当天已触发过不会重复（服务重启错过触发点，30 分钟内仍补跑）。每用户一条排程，开关/时刻即时生效。

### 9. 运行历史与达标预测

- 每次引擎运行落库（触发方式 manual/schedule、结束原因 completed/quota/stopped/error、已提交轮次），供回溯；
- 总览自学轨按近 4 周周均速推算「预计 M 月 D 日达标」，已达标本项显示「已达标」，暂无节奏数据显示引导语。

### 10. 必修优先

引擎任务排序：必修课在前，选修与专题在后（同优先级保持原有顺序）。

### 11. 课程详情预览

任务表每行「详情」：按平台课程大纲展开章节与小节（名称、文件类型、时长），启动引擎前先看清会跑什么、会跳过什么。

### 12. 任务导出 CSV

任务表一键导出（任务名/类型/必修/状态/已学学时/截止），带 BOM 与 CRLF，Excel 直接打开不乱码。

### 13. 音效与后台通知

Web Audio 合成音效（无音频资源），只在关键事件给确认：起步、完成、出错、停止、登录成功；顶栏静音开关，偏好存 localStorage。页面切到后台时，引擎停止改用系统通知提示（权限授予才发，被拒则静默）。

## 非目标（明确不做，由 extension 分支承担）

| 能力 | 不做的理由 |
| :-- | :-- |
| 官网登录态无感导入 | 需要浏览器扩展共享 localStorage，web 版拿不到 |
| 无人值守「真实播放」看课 | 必须驱动平台页面里的真实播放器；web 引擎走接口上报路线 |
| 多标签页状态同步 | 单页应用天然单实例 |
| 双轨分发（商店版/完整版） | 本地/私有部署，无商店审核问题 |

## 安全与边界（如实告知）

- **学时来源**：web 版引擎与油猴脚本同源，通过平台接口回填学时（createTime + 分段上报），**不是**在页面里真实播放。这 extension 分支「零上报、零伪造」的产品口径不同——extension 是真实播放版，web 是接口版，两者并存、用途互补，本文如实记录差异。
- 平台侧随机化与熔断（≤90s 上限、随机间隔、配额自动停）用于控制账号风险，但账号风控责任由使用者自担；仅供学习研究，风险自负。
- 平台密码加密落库、令牌不落盘、日志不含密码；站点密码与平台密码相互独立，站点被攻破不等于平台密码泄露（AES 密钥在服务端环境变量）。
- 限流防爆破：认证 30 次/15 分钟/IP，平台登录失败不重试。

## 部署形态

- 本地开发：`bun install && bun dev`（tsx :8080 + vite :5173，SQLite）。
- 生产：Docker Compose 或 WSL 容器（wslc，无 Docker Desktop 时）——app + PostgreSQL 16 + Nginx 80，镜像内自动 `prisma db push`，Nginx 反代 `/api` 并补真实 IP；健康检查 + 优雅停机。步骤见 docs/DEPLOY.md。

## 数据模型（简）

| 表 | 内容 |
| :-- | :-- |
| users | 站点账号：用户名、scrypt 密码哈希 |
| platform_bindings | 平台凭据：AES-256-GCM 密文（iv + authTag + data）、单位名 |
| sessions | 会话：sha256(token)、过期时间 |
