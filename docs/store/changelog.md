## 2.11.1

## 2.11.0

- 全新「自动学习值守」：在学院课程页或专题页点击扩展工具栏图标即可开启，无需进控制台——
  自动将视频切为普清、固定标签页并静音，按小节顺序连续播放；专题内播完一门自动回专题页
  进入下一门，全部完成后值守自动结束
- 工具栏图标状态角标：值守运行中显示 ▶（绿）播放中 / …（橙）处理中，停止后清除；
  悬停可看当前动作，随时再点一次图标即停止
- 控制台顶栏实时状态徽标：值守中常驻显示当前视频名与进度（超长自动省略，悬停看完整
  专题 › 视频详情，点击直达运行日志）
- 任务列表值守期间每 90 秒自动刷新学时进度（页面不可见时暂停，不浪费请求）
- 运行日志新增值守关键事件（开启 / 进入课程 / 小节 100% / 结束），本地持久化——
  控制台关闭再打开仍可回看；每次值守会话在「运行记录」中生成一条，结束后自动收尾
- 稳定性修复：值守严格限定单个标签页推进，不再出现重复开标签页；被平台跳转带走时
  自动返回当前学习位置；登录过期时提示重新登录后从断点继续
- 适配 Firefox：首次提供 Firefox（AMO）版本，Manifest V3 事件页后台，权限声明与
  Chrome 版一致（仅 storage + 平台域名按需授权）
