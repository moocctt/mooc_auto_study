# 权限申辩文案（CWS Privacy practices 填写用）

> 版本: 2026-11-09 · 对应 manifest v2.11.x（permissions: storage + alarms / optional_host_permissions: mooc.ctt.cn / content_scripts: mooc.ctt.cn）
> 用途: 每次提交新版本时，Privacy practices 表单的申辩字段从这里复制。文案必须与实际行为一致 —— 行为变更时同步更新本文件。

## 1. `storage` 权限申辩

用于在本机扩展存储中保存你的登录令牌、账号列表、学习进度偏好与统计数据（如热力图历史）。所有数据仅存于本机浏览器，不上传任何服务器；可在扩展设置中随时一键清除。

## 1b. `alarms` 权限申辩

仅用于在登录令牌自然到期的那一刻唤醒一次后台，把工具栏图标/角标刷新成「需重新登录」。不读取任何数据、不常驻运行；`alarms` 属于不弹授权提示的静默权限（与 `storage` 同类），安装时不会向用户展示额外警告。

## 2. 主机权限申辩（mooc.ctt.cn）★ 发布必填

用于访问烟草网络学院（mooc.ctt.cn）官方接口：读取你本人账号的学习进度、任务清单与 12 类课程内容，以及完成登录（扫码 / 账号密码 / 一键导入官网登录态）。仅在用户使用扩展功能时访问该域名，所有数据只存本机扩展存储，不上传任何服务器。

## 3. 内容脚本说明（表单问及"网站内容读取"时）

扩展在学院官网（mooc.ctt.cn）页面注入一个内容脚本，仅用于读取你本人已登录的登录令牌（localStorage 中的 token 字段），实现「一键导入官网登录态」。不修改页面内容，不上传页面数据，仅在用户授权后运行。

## 4. 数据使用声明（表单问及收集了什么时）

扩展不收集、不传输任何个人数据到开发者服务器。所有数据（账号、令牌、学习记录、偏好）仅存储在本机浏览器扩展存储中；可选「凭据同步」使用浏览器自带的同步服务（默认关闭），与本扩展开发者无关。
