隐私政策 · 烟草网络学院学习助手

最后更新：2026-11-09 · 非官方扩展，与学习平台及其运营方无关联

一、处理的数据

数据用途存放位置
平台账号（用户名/手机号）登录你本人的学习账号、展示姓名本机扩展存储
平台密码仅当你勾选「记住凭据」时保存，用于登录态到期前自动续期（有效期由平台按登录方式下发，账密与扫码不同）本机扩展存储；未勾选时仅当前标签页会话；开启「凭据同步」时另存于浏览器内置同步
会话令牌（有效期由平台下发）免重复登录、读取学习数据本机扩展存储
学院官网页面登录令牌当你已在本机登录过学院官网且已授权扩展访问时，从官网页面读取你的登录令牌用于一键登录仅存本机扩展存储，导入成功即删除；未授权访问时不会读取
学习数据（学时/任务/小节进度/截止时间）账单、统计、热力图、截止提醒与推荐本机（仅展示用缓存）
本地偏好与学习历史记住设置、运行记录、每日学时（热力图与统计）本机
自动学习值守状态（运行开关、当前课程/视频名、进度、运行日志）工具栏角标与面板实时状态、运行日志回放本机扩展存储

二、可选：凭据同步

默认关闭。开启后（设置 → 偏好 → 「凭据同步」），勾选「记住凭据」保存的密码会经浏览器内置同步 （chrome.storage.sync，由你的 Chrome/Edge 账号提供）在已登录同一浏览器账号的设备间共享， 云端副本由浏览器厂商按你的账号存储。登录令牌不同步，每台设备各自维护；关闭同步会删除云端密码副本， 「清除本机数据」也会同步清空云端密码。公共或共享电脑请保持关闭。

三、我们不做什么

  • 不上传任何数据到自有服务器；不出售、不共享、不用于广告或画像
  • 不收集与学习无关的浏览记录、剪贴板或输入内容

三之二、可选功能：自动学习辅助

你可以在课程/专题页点击扩展图标开启「自动学习值守」：由扩展在你本人已登录的平台页面内， 代替手动操作播放器（切换清晰度为普清、静音并固定标签页、按小节顺序连续播放）。该功能：

  • 仅在本地浏览器内运行，使用你自己的登录会话，不会获得额外权限或额外数据
  • 不修改平台数据、不伪造学习记录，学时由平台按其自身规则记录
  • 运行状态（当前视频、进度、日志）只保存在本机，随时可点击图标停止

四、与平台的通信

扩展仅与你本人的学习平台 https://mooc.ctt.cn 通信，请求由你的浏览器直接发出。 「用当前登录态打开官网」会把会话令牌放在平台域名 URL 的 fragment（#access_token=…）中打开新标签页，fragment 不会随请求发送到服务器。

五、权限

  • storage：保存账号标识、令牌、偏好与本地学习数据
  • alarms：仅在登录令牌到期的那一刻唤醒一次后台，把工具栏图标刷新为「需重新登录」；不读取数据、不常驻运行
  • optional_host_permissions: https://mooc.ctt.cn/*：读取你本人账号的学习进度与任务（功能必需，首次使用时由你点击授权）；在你已登录的官网页面读取登录令牌（一键导入登录态）
  • storage 中的 sync 子项：仅在你开启「凭据同步」后写入密码副本，随之同步到你的其它设备

六、保留与删除

数据保存在本机，直到你删除：设置 → 关于与隐私 → 「清除本机数据」，或卸载扩展。删除仅影响本机缓存与登录态，不影响平台学习记录。 若开启了凭据同步，删除时会同时清空浏览器同步中的密码副本；关闭同步同样会删除云端副本。

七、儿童

本扩展面向成年人本人账号使用，不面向未满 18 周岁用户。

八、风险提示

平台对自动化学习有检测与处罚规则（可能清空学时、封禁账号）。自动学习辅助功能默认关闭， 仅在你主动点击图标后运行、随时可停；是否使用请自行评估并遵守平台用户协议。
