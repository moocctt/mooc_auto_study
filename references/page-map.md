# 页面地图与文本锚点

站点：**中国烟草网络学院** `https://mooc.ctt.cn`
技术形态：Vue 单页应用，hash 路由（`https://mooc.ctt.cn/#/...`），内容异步渲染。
主办：中国烟草总公司职工进修学院；客服 400-8596-800。

## 定位策略

**优先用可见文本定位，不要用 class 选择器。** Vue 的 scoped class 带构建哈希，随发版变化；文本锚点稳定得多。

操作顺序：
1. 读可见 DOM（工具名随宿主而定：DOM 工具 / Playwright / CUA）；
2. 在返回结果里按锚点文本找节点；
3. 点击 / 输入；
4. 页面变化后**重新读 DOM**（旧节点标识立即失效）。

只有当 DOM 里确实没有对应文本（画布、图片按钮、iframe 内嵌播放器）时，才截图后按坐标操作。

**登录不走这里。** 微信扫码用 `python scripts/mooc_api.py qr wechat`（出码即发 widget，扫到自动落盘），
已知账号可以只发卡片：`python scripts/mooc_api.py card --account <手机号>`。本文的页面路径只在需要人工
核对/校准，或需要看平台原文时才用。

## 已知入口

| 位置 | 锚点文本 | 说明 |
| --- | --- | --- |
| 首页右上 | `登录` | 未登录时出现 |
| 首页顶部导航 | `总院` | 下拉菜单含各分院（如农业分院） |
| 首页顶部导航 | `活动` | 培训班公开报名入口 |
| 登录后导航 | `个人学习中心` 或 `学习中心` | 学习任务主入口 |
| 学习中心内 | `我的班级` | 培训班、班级附件、日程 |
| 学习中心内 | `我的学习` / `我的课程` | 课程与学时进度 |
| 学习中心内 | `我的考试` | 在线考核 |
| 学习中心内 | `我的证书` | 电子培训证书 |
| 页脚 | `禁止刷课` | 平台明确禁止，见 SKILL.md 硬性边界 |

登录后的准确导航名称随角色与版本略有差异。找不到「个人学习中心」时，先点用户头像/姓名展开下拉，再在其中找「学习中心」「我的空间」等近义项。

## 登录弹窗

正常登录走 `mooc_api.py qr`，这一节只用于人工核对弹窗文案与校准。
平台登录页的一个已知路由形态：`#/staticConfigNew/1/79d34a46-9e90-47ce-8eb8-d56c0ce274f4`。弹窗内文本锚点：

| 二维码过期 | `二维码已失效` `请点击刷新` |
| 切换账号登录 | `账号登录` |
| 账号表单 | `请输入账号手机号` `请输入密码` `记住账号密码` |
| 表单按钮 | `找回密码` `注册` `登录` |

## 采集页签与字段映射

| 页签名 | 典型字段 | 映射到 |
| --- | --- | --- |
| 我的班级 | 班级名称、培训起止、状态、进度 | `class_name` / `deadline` / `progress` |
| 我的学习 / 我的课程 | 课程名、必修/选修、学时、学习进度、完成状态 | `title` / `required` / `hours` / `progress` |
| 我的考试 | 考试名称、截止时间、成绩、是否通过 | `kind=exam` / `deadline` / `platform_status` |
| 我的证书 | 证书名称、发证日期 | 仅汇报，不建任务 |
| 班级附件 | 日程表、名额分配表 | 提示用户下载，不解析内容 |

进度文本形态多样：`45%`、`45`、`1.5/4学时`、`已完成`、`未开始`。脚本的 `to_progress` 已兼容前四种；遇到 `1.5/4学时` 这类分数形式时，自行算百分比后再写入。
